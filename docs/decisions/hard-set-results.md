The hard set is small, AI-drafted and AI-verified. It was drafted with AI assistance, then reviewed by the AI against public sources (`docs/decisions/hard-set.md`, `docs/hard-set-verification.md`); the project owner did not review it. ## How to read it

Dev is optimistic: the generator and the engine share GeoNames and the guide's word lists, and the engine was tuned on dev until it stopped finding failures. Calibration was seen once, for reporting, during the Day 2 audit. The hard set is the independent read of how the engine behaves on addresses it was not built from, and it is small. A drop from dev to the hard set is the size of the optimism, not noise to be tuned away. The false-repair rate (ACCEPT with any wrong field, out of all ACCEPT records) is the number that matters most, and its k/n is shown for every split.
